// Master document. Each chapter file is written with its own top-level
// `= Title` so it's a valid standalone AsciiDoc document on its own
// (readable/previewable in isolation). To make that work inside a book,
// we write a real `= Part N: ...` heading here for each part, then include
// that part's chapters with a per-include `leveloffset=+1` attribute so
// each chapter's `=` shifts down to `==` and nests under the part, instead
// of every chapter file trying to be its own book part.
//
// NB: use the per-include `leveloffset=+1` attribute (not a standalone
// `:leveloffset: +1` / `:leveloffset: 0` document-attribute pair) — in
// this Asciidoctor version, resetting the global `:leveloffset:` attribute
// between parts does not actually restore level 0, which demotes every
// subsequent `= Part N` heading into a chapter nested under the previous
// part instead of a sibling part. The per-include attribute is scoped to
// that include only, so it doesn't leak into later headings.
