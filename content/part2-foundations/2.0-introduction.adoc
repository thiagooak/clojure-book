= Foundations

Welcome to Clojure!

This part is a gentle introduction to the basics of Clojure. It's intended
to be read in order — later pages build on material from earlier ones.
Each page ends with a few exercises.

By this point in the book you've already deployed something real (Part 1)
— this part is where you build the vocabulary to understand what you just
shipped, and to start changing it on purpose instead of by trial and
error.

This part covers:

* <<ch-2-1-syntax,Syntax>>
* <<ch-2-2-functions,Functions>>
* <<ch-2-3-sequential-collections,Sequential Collections>>
* <<ch-2-4-hashed-collections,Hashed Collections>>
* <<ch-2-5-flow-control,Flow Control>>
* <<ch-2-6-namespaces,Namespaces>>
